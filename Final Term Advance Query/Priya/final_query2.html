Customer Retention: Days Between Orders

Analysis Description

This report tracks the Purchase Velocity of customers using window functions. By calculating the difference between a customer's current and previous order dates, we identify churn risks and loyalty patterns.

  • LAG Function: Used to retrieve the date of the customer's previous transaction without multiple self-joins.
  • DATEDIFF: Calculates the exact number of days between visits to measure engagement.
  • Strategic Value: Helps Starbucks identify if customers are visiting more frequently (low days between orders) or if the gap is widening.
