Starbucks Customer Ordering Patterns – Final Term SQL Project

This project analyzes Starbucks customer ordering behavior using a normalized MySQL database built from a dataset containing 100,000 transactions across 500 stores and 14,988 customers (2025–2026).

Project Goals:
- Clean and normalize the dataset into relational tables
- Analyze customer ordering patterns using SQL
- Generate business insights through basic and advanced queries
- Build an interactive dashboard for visualization

Technologies Used:
- MySQL
- Flask
- HTML/CSS
- Chart.js
- Python

Files Included:
- Final Term Query.pdf → My complete report for Basic and Advance Query with result.
- Query.sql → All SQL queries used in the project
- Starbucks Final Dashboard.html → Interactive dashboard visualizations
- app.py → Flask backend application
- db.py → Database connection file
- templates/ → HTML templates for dashboard rendering

Key Analysis Areas:
- Order channel performance
- Customer spending behavior
- Store revenue analysis
- Customer satisfaction trends
- Drink category preferences
- Query optimization using indexing
- Customer segmentation and ranking

Dashboard Features:
- Revenue analysis charts
- Customer behavior visualizations
- Channel performance comparisons
- Satisfaction and fulfillment analysis
- Seasonal sales trends
